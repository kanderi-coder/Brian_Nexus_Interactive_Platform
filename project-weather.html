Digital Weather Monitoring

A microcontroller-based concept for collecting and presenting local weather readings.

Project overview

The project direction involves a board such as an ESP32 or ESP8266, environmental sensors such as DHT11/DHT22, a rain sensor, and a local display. A dashboard or database can be treated as a later extension once the sensor pipeline is working and verified.

Design goals

  • Read sensor values consistently.
  • Show the latest readings on a display.
  • Handle missing or invalid sensor readings clearly.
  • Consider storage and dashboards as separate, testable stages.

Project concept / development direction. Only mark hardware, dashboards, or database features as completed once they have been tested.
