EchoDesk AI

A desktop assistant project exploring more natural ways to interact with a computer.

Project overview

EchoDesk is a personal desktop-assistant project. Its intended direction combines a desktop interface with AI conversation, optional local or online model providers, voice interaction, screen understanding, and carefully controlled computer actions. The exact availability of each capability depends on the current build and configuration.

Design goals

  • Keep the assistant interface lightweight and unobtrusive.
  • Separate intent routing, planning, and execution.
  • Make desktop actions understandable and permission-aware.
  • Test changes before adding more complexity.
