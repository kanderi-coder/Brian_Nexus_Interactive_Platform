BRIAN NEXUS — INTERACTIVE PORTFOLIO STARTER

WHAT'S INCLUDED
- Multi-page responsive portfolio: Home, About, Skills, Projects, Nexus Lab, Journal, Contact
- Three project detail pages
- Shared dark/gold visual system
- Mobile navigation and subtle scroll reveal
- Nexus Lab expense demo: entries are stored in this browser only (localStorage)
- Weather dashboard concept with clearly labelled simulated data
- Contact form that prepares an email draft in the visitor's email application

HOW TO RUN IN VS CODE
1. Extract this ZIP to a folder, for example Documents\brian_nexus_platform.
2. Open that folder in VS Code: File > Open Folder.
3. If you have Live Server installed, right-click index.html and choose "Open with Live Server".
4. Otherwise, double-click index.html to open it in a browser. Live Server is recommended.

IMPORTANT
- This is a front-end starter; it has no backend, account system, database, or server-side email.
- The weather display uses sample data, not live weather or physical sensor data.
- Project descriptions distinguish project direction from verified completed functionality.
- Update contact information, education details, GitHub links, and project statuses before publishing.
- The contact form opens a prefilled email draft; it does not send the message itself.
- Google Fonts require an internet connection; the site remains usable with fallback fonts.
